# Refonte du site CEFISI

Ce projet porte sur la refonte complète de `www.cefisi.com` : le site public, l'administration des contenus et un espace documentaire pour les étudiants et l'équipe pédagogique. La plateforme `candidatures-cefisi.com` reste distincte ; le nouveau site conservera un lien vers elle.

Le projet est en phase de conception. Les besoins, les maquettes et les choix techniques sont documentés dans `docs/`.

**Équipe projet :** Mattéo, Romain, Tim et Cal-Sebastien.

## Organisation

| Dossier | Utilité |
|---|---|
| `docs/cadrage/` | Objectifs et périmètre du projet |
| `docs/conception/` | Fonctionnalités, difficultés techniques et choix à discuter |
| `docs/observations/` | Relevés et observations sur le site actuel |
| `docs/inventaire/` | Inventaire des pages et des médias |
| `docs/maquettes/` | Maquettes des parcours et des interfaces |
| `docs/charte-graphique/` | Proposition de couleurs et de principes visuels |
| `docs/matrice/` | Matrice des rôles et des droits |
| `docs/medias/` | Manifeste et documentation des médias du site actuel |
| `docs/presentation-client/` | Synthèse du projet et questions à discuter avec CEFISI |
| `docs/pilotage/` | Notes de pilotage du projet |
